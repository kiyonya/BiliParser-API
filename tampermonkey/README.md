# 复制B站视频解析站地址

当您在使用VR头显时复制浏览器的文本以及编辑链接并不方便，您可以尝试这个油猴（Tampermonkey）脚本，在 B 站视频页 / 直播页左下角注入一个按钮，点击后将解析站链接复制到剪贴板，粘贴后即可快捷播放。

## 安装步骤

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)
2. 点击 Tampermonkey 图标 → **添加新脚本**
3. 删除默认模板内容，将 `script.js` 的完整内容粘贴进去
4. 保存生效

## 使用方法

当打开视频播放页或者直播页时左下角会出现粉色按钮，点击复制即可
